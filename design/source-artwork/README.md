# Source artwork

The **original** files as supplied, before any processing. Kept here because
the deploy folder (`~/Downloads/honeybadger-school-site`) is wiped on every
refresh, and this was the only copy.

`Honey badger final logo.png` — 1080×579, **no alpha channel**, ~63% empty
white margin.

`src/assets/logo.png` and `logo-mark.png` are derived from it: flood-filled
from the corners to transparency, feathered, cropped to the artwork. If new
artwork arrives, re-run that processing — do not drop a raw white-background
PNG onto the honey-paper background.
